## Pre-Release

For file choices for this project are (rename all `blackhosts_*` files to just `blackhosts` if you like):

|File|Description|
|:---:|:---:|
|blackhosts_linux|The main compiled binary executable for Linux|
|blackhosts.deb|A *Debian* `.deb` package installer for the `blackhosts_linux` file; not necessary, just convenient |
|blackhosts_macos|The main compiled binary executable for MacOS|
|blackhosts_windows.exe|The main compiled binary executable for Windows|
